# Illustrative negotiation examples

These examples are written planning fixtures. They are not recorded agent outputs, hardcoded production responses, or a promised live winner.

## A useful buyer counter

Public offer: Studio Stack proposes Nova M2, AirMic Kit, and StandMini with standard delivery. The package is more expensive than the buyer wants.

Buyer action: request the wired ToneClip instead of AirMic, preserve Nova M2, and request an accessory-price concession. Reason shown to user: "A wired microphone meets your requirement. I am protecting camera quality and asking for a leaner bundle."

Seller action: propose only listing IDs belonging to Studio Stack, choose prices within the versioned floors, use listed standard shipping, and keep the fixed 24-month demo warranty. The application calculates the payable amount.

## A valid refusal

Pixel Port's Nova M2 + ToneClip + StandMini with eligible express shipping has a $435 minimum. If the user insists on that camera and a $430 cap/four-day delivery, Pixel Port must decline or propose an ineligible negotiating position. It can offer a Vela substitution only if the confirmed brief allows it.

Good message: "I can meet this budget with Vela C1. I cannot offer this Nova M2 kit within $430 and your delivery window."

Invalid message: "I will waive express shipping and include an unlisted warranty" when the policy permits neither.

## Payment continuity

If the user selects the $419 Studio offer, the review and PayPal order both show the same three items, $10 shipping, USD currency, and $419 total. A later message claiming a new discount cannot change this checkout. The user must cancel safely and select a fresh offer if they want different terms.
